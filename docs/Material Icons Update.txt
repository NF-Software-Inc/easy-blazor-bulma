UPDATING THE MATERIAL SYMBOLS FONT
==================================

This project uses Google's Material Symbols font (the current set, built with variable font technology).
The font files are located in: easy-blazor-bulma/wwwroot/fonts/iconfont/


STEP 1: DOWNLOAD THE MATERIAL SYMBOLS FONT (WOFF2 FORMAT)
-------------------------------------------
1. Go to: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined
2. Open the browser's developer tools (F12 or right-click > Inspect)
3. In the Sources or Network tab, you can see the referenced font file
4. Alternatively, view the page source and look for the URL containing "MaterialSymbolsOutlined" with the .woff2 extension
5. Download the .woff2 file directly from that URL

The Google Fonts CDN provides the latest Material Symbols font in WOFF2 format, which is the most efficient for web use.


STEP 2: CONVERT TO WOFF FORMAT
-------------------------------------------------
Use CloudConvert to convert the WOFF2 file to WOFF format (for broader browser compatibility):
1. Go to: https://cloudconvert.com/woff2-to-woff
2. Upload the downloaded WOFF2 file
3. Click "Convert" and download the resulting WOFF file

Optionally, use Font Squirrel to build an optimized font bundle:
1. Go to: https://www.fontsquirrel.com/tools/webfont-generator
2. Upload the WOFF file you just converted
3. Select "Expert" mode
4. Configure these options:
   - Format: Select both "WOFF" and "WOFF2"
   - Rendering: Keep Existing
   - Fix GASP Table: Enable
   - X-Height Matching: No Adjustment
   - Protection: Spaces and Hyphens
   - Subsetting: No Subsetting (to include all Material Symbols icons)
5. Click "Download Your Kit"


STEP 3: REPLACE THE FONT FILES
-------------------------------
Extract the downloaded files and replace the fonts in:
  easy-blazor-bulma/wwwroot/fonts/iconfont/
  
Required files:
  - materialicons-regular-webfont.woff
  - materialicons-regular-webfont.woff2

These are the optimized font files generated by Font Squirrel that are compatible with all browsers.


STEP 4: TEST THE UPDATE
-----------------------
To verify the update was successful, test with some recently added Material Symbols icons.
These icons should display as proper icon symbols (not as text):

1. Run the demo application or include the library in a test project
2. Test these recently added icons:
   - youtube_activity
   - youtube_searched_for
   - zone_person_alert
   - zone_person_idle
   - zone_person_urgent
   - wrap_text
   - wrist
3. Display them using: <span class="material-icons">icon_name</span>
4. Icons should render as proper icon symbols (not as text)

If icons appear as text instead of symbols, the font files may not have been properly replaced or generated.

For a complete list of available icons, visit: https://fonts.google.com/icons
